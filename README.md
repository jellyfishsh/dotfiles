# Bloomforge

Bloomforge (bforge) is a "dotfile setup" (moreso a reproducible environment) for my development environment on **Void Linux**.
In addition to dotfiles, it also includes setup for the tools instead.

## Tools
* neovim (btw)
* tmux
* river
## Requirements
* git
